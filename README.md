# Website PT Dendigma Jaya Indonesia

Website company profile statis (HTML, tanpa build step) untuk PT Dendigma Jaya Indonesia: custom box packaging, gift box, tumbler, plakban, dan sticker seal.

- `index.html` halaman utama
- `img/` foto produk dan logo
- `favicon.png` ikon tab (logo DJI)
- `company-profile.pdf` company profile A4 yang bisa diunduh

Deploy: Vercel, framework "Other", tanpa build command, output directory root.
